# TradingSpy ACP Skills

This folder exposes reusable skills so other agents can call TradingSpy through ACP without using the UI.

## Skill: `tradingspy-ui-assistant-acp`

Use this skill when an external agent needs the **same workflow runtime as the web UI**.

- Protocol: ACP v0.2
- Base URL: `http://localhost:8000/acp`
- ACP agent name: `ui-assistant`
- Auth: optional bearer token (`Authorization: Bearer <REMOTE_AGENT_AUTH_TOKEN>`) when configured

### General assistant mode (same as UI chat)

If you send plain text (or JSON with `prompt` / `message`) **without `workflow`**, ACP `ui-assistant` uses the same backend chat path as the UI:

- `/api/backtest/ai/chat-with-tools`

This supports normal questions, analysis, and tool-using conversational requests.

### Supported UI workflows

- `market_review`
- `strategy_create`
- `strategy_race`
- `fundamental_screener`

## How to call

### 1. Discover agents

`GET /acp/agents`

### 2. Create a run

`POST /acp/runs`

Body:

```json
{
  "agent_name": "ui-assistant",
  "input": [
    {
      "role": "user",
      "parts": [
        {
          "content_type": "application/json",
          "content": "{\"workflow\":\"strategy_race\",\"prompt\":\"Generate until it beats buy and hold for QQQ\",\"ticker\":\"QQQ\"}"
        }
      ]
    }
  ]
}
```

If `workflow` is omitted, runtime intent fallback is used from `prompt`.

For general chat mode, you can also send:

```json
{
  "agent_name": "ui-assistant",
  "input": [
    {
      "role": "user",
      "parts": [
        {
          "content_type": "text/plain",
          "content": "What are the strongest and weakest industries today?"
        }
      ]
    }
  ]
}
```

### 3. Check run

`GET /acp/runs/{run_id}`

The run output includes:

- `agent_run_id` (underlying UI runtime run id)
- `workflow`
- `status`
- `progress`
- `current_step`
- `summary_text` / `summary` / `outcome`
- `accepted_version` and benchmark fields (when applicable)

# TradingSpy Agent Tools (MCP / function calling)

Use this when an external agent (opencode, Hermes, any OpenAI function-calling
client) should call **TradingSpy functions directly as tools** while keeping its
own LLM for reasoning. TradingSpy provides deterministic data and compute only:
no deletes, no resets, no LLM calls.

Enable it in Settings ("Agent Tools (MCP)") or with `ENABLE_AGENT_TOOLS=true`.
Auth: optional bearer token (`Authorization: Bearer <REMOTE_AGENT_AUTH_TOKEN>`)
when configured.

## Surfaces

| Surface | Endpoint | For |
| --- | --- | --- |
| MCP server (JSON-RPC) | `POST http://localhost:8000/mcp` | opencode, Claude Desktop, any MCP client |
| OpenAI tool manifest | `GET http://localhost:8000/api/tools/manifest` | Hermes, OpenAI function-calling agents |
| Generic invoke | `POST http://localhost:8000/api/tools/invoke` | Any HTTP client |

## Tools (26)

`list_datasets`, `check_data`, `download_data`, `get_quote`, `batch_quotes`,
`ticker_info`, `get_news`, `get_technicals`, `get_earnings`,
`get_analyst_recommendations`, `get_insider_trades`, `get_market_movers`,
`screen_fundamentals`, `list_strategies`, `get_strategy`, `run_backtest`,
`get_task`, `etf_holdings`, `peers`, `expected_pattern`, `chart`,
`industry_heatmap`, `sector_heatmap`, `trading_signal`, `pattern_scan`,
`render_chart_image`.

`run_backtest` and `screen_fundamentals` block for up to
`AGENT_TOOL_BLOCK_SECONDS` (default 120s) and then return a `task_id`; poll it
with `get_task`.

`render_chart_image` returns a **branded TradingSpy PNG** (`"Generated by
TradingSpy"` footer) as MCP image content (and base64 JSON via `/api/tools/invoke`):
`kind="candles"` (OHLCV), `kind="expected_pattern"` (forecast path + 80% band),
or `kind="pattern_detection"` (candles with detected-pattern markers). Example:
*"render a SPY expected-pattern chart image"* → the agent gets back an inline PNG.

## opencode setup

Add to `opencode.json` (project) or `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "tradingspy": {
      "type": "remote",
      "url": "http://localhost:8000/mcp",
      "enabled": true,
      "headers": { "Authorization": "Bearer ${REMOTE_AGENT_AUTH_TOKEN}" }
    }
  }
}
```

Restart opencode, then ask things like *"What's SPY's RSI and latest news?"* —
the agent calls `get_technicals` and `get_news` itself.

## Hermes / OpenAI-style agents

1. Fetch the manifest: `GET /api/tools/manifest` → pass as `tools:` in your
   chat completion request.
2. When the model emits a tool call, execute it:

```bash
curl -X POST http://localhost:8000/api/tools/invoke \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <REMOTE_AGENT_AUTH_TOKEN>' \
  -d '{"name":"run_backtest","arguments":{"dataset_filename":"spy-1d-max.txt","strategies":["SMACross"]}}'
```

3. Feed the JSON result back to the model as the tool result.

## Raw MCP example

```bash
curl -X POST http://localhost:8000/mcp -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

curl -X POST http://localhost:8000/mcp -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"get_quote","arguments":{"ticker":"SPY"}}}'
```
